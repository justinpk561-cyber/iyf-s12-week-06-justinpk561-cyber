# Week 06: Asynchronous JavaScript

## Project Overview
This repository contains my Week 06 IYF Weekend Academy assignments.

The main project is a Weather Dashboard that fetches real-time weather information using the OpenWeatherMap API.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Promises
- Async/Await
- OpenWeatherMap API
- GitHub Pages

## Lessons Completed
- Lesson 11: Callbacks, Promises and Async/Await
- Lesson 12: Working with APIs

## Weather Dashboard Features
- Search weather by city.
- Display temperature in Celsius.
- Display weather descriptions and icons.
- Show humidity, wind speed and pressure.
- Display feels-like temperature.
- Save the five most recent searches.
- Handle invalid city searches and errors.
- Responsive design for mobile devices.
